Why not an overlay

Overlay widgets promise a one-line install. Here is what the record shows.

  • An overlay runs on top of your published site. It doesn't change the HTML and CSS underneath, so the barriers a screen-reader user hits are frequently still there. We fix the code the browser actually serves.
  • Regulators have scrutinized overlay marketing directly. The FTC's order against overlay vendor accessiBe (announced January 2025, finalized April 2025) required a $1 million payment over claims about what its automated tool delivered.
  • ADA web complaints increasingly name overlay widgets by name. Adding one changes what a plaintiff sees, not necessarily what a screen reader encounters — and it is not a settled defense.
